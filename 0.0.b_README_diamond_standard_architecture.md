## 🚀 Quick Start

### 1. Install Dependencies

```bash
# Install system dependencies (Ubuntu/Debian)
sudo apt-get update
sudo apt-get install python3-pip python3-dev libcairo2-dev

# Install Python packages
pip install -r 0.0.a_requirements_intent_manifest.txt
```

### 2. Set Up Asset Libraries

```bash
# Create library directories
mkdir -p libraries/fonts
mkdir -p libraries/icons/{tech,business,nature}
mkdir -p libraries/decorations/{corners,patterns}
mkdir -p libraries/backgrounds

# Copy provided assets
cp 1.1_*.json libraries/fonts/
cp 1.2.a_*.svg libraries/icons/tech/
cp 1.2.b_*.svg libraries/icons/business/
cp 1.2.c_*.svg libraries/icons/nature/
cp 1.3.a_*.svg libraries/decorations/corners/
cp 1.3.b_*.svg libraries/decorations/patterns/
cp 1.4_*.json libraries/backgrounds/
```

### 3. Run Server

```bash
python server_main.py
```

Server starts on `http://localhost:5000`

### 4. Generate Your First GIF

```bash
# Basic generation (3 frames)
curl "http://localhost:5000/generate?count=3" -o marketing.gif

# Custom company & services
curl "http://localhost:5000/generate?company=TechCorp&services=AI,Cloud,Data&count=5" -o marketing.gif

# Full customization
curl "http://localhost:5000/generate?company=Brand&services=A,B,C&bg=blue&text=white&font=tech&geometry=sharp&count=5" -o marketing.gif
```

## 🎨 URL Parameters

### Available Parameters:

| Parameter | Description | Example | Default |
|-----------|-------------|---------|---------|
| `count` | Number of frames | `?count=5` | `3` |
| `seed` | Specific seed (reproducible) | `?seed=12345` | Random |
| `company` | Company name | `?company=TechCorp` | `Your Company` |
| `services` | Comma-separated services | `?services=AI,Cloud,Data` | `[]` |
| `bg` | Background color | `?bg=blue` or `?bg=%231a4d7a` | Seed-based |
| `text` | Text color | `?text=white` | Seed-based |
| `accent` | Accent color | `?accent=yellow` | Seed-based |
| `font` | Font style | `?font=tech` | Seed-based |
| `geometry` | Shape style | `?geometry=sharp` | Seed-based |
| `random` | Full random mode | `?random=true` | `false` |

### Font Styles:
- `bold` - Bold, impactful
- `tech` - Monospace, technical
- `elegant` - Serif, sophisticated
- `blocky` - Heavy, attention-grabbing
- `script` - Flowing, creative

### Geometry Styles:
- `sharp` - Angular, modern
- `round` - Circular, friendly
- `mixed` - Combination of shapes
- `minimal` - Subtle accents

## 🎯 The Diamond Standard Principles

### 1. **Ghostless Naming**
Every identifier is self-documenting:
```python
validate_authentication_token_intent()  # Not: auth()
generate_frame_from_seed_intent()        # Not: gen()
compose_shapes_in_safe_zones_intent()    # Not: add_shapes()
```

### 2. **Writable Doctrine**
Only validated data enters the pipeline:
```python
# Pre-execution validation
writable_params = validate_parameters_as_writable_for_generation_intent(raw_params)

# Invalid params rejected at gate
# All rejections logged with context
```

### 3. **Contextual Logging**
Logs ARE the documentation:
```python
# No separate comments needed
log_intent_execution_with_full_context_intent(
    intent_key='generateFrameFromSeedIntent',
    execution_payload={'seed': 12345, 'params': {...}},
    execution_outcome='FRAME_GENERATED_SUCCESSFULLY'
)
```

### 4. **Precedence Architecture**
User intent ALWAYS wins:
```
User Override > Seed-Based Generation > System Default
```

### 5. **Boundary Enforcement**
Text NEVER overflows, shapes NEVER collide:
```python
# Binary search auto-fitting
optimal_font_size = binary_search_font_size_that_fits_boundaries()

# Safe zone calculation
safe_zones = calculate_zones_excluding_text_with_margins()
```

## 🚀 Production Deployment

### With Gunicorn (Recommended):

```bash
# Install gunicorn
pip install gunicorn

# Run with 4 workers
gunicorn -w 4 -b 0.0.0.0:5000 server_main:app

# With logging
gunicorn -w 4 -b 0.0.0.0:5000 \
  --access-logfile access.log \
  --error-logfile error.log \
  server_main:app
```

### With Docker:

```dockerfile
FROM python:3.11-slim

RUN apt-get update && apt-get install -y libcairo2-dev

WORKDIR /app
COPY . /app

RUN pip install -r 0.0.a_requirements_intent_manifest.txt
RUN pip install gunicorn

EXPOSE 5000

CMD ["gunicorn", "-w", "4", "-b", "0.0.0.0:5000", "server_main:app"]
```

### With Nginx Reverse Proxy:

```nginx
server {
    listen 80;
    server_name marketing-api.example.com;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
```
